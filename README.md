# Café Origen — Motor de Analítica de Ventas (`v0.1`)

Herramienta de línea de comandos desarrollada en **Node.js** para procesar, limpiar y analizar el historial de ventas de **Café Origen**, generando indicadores clave para la toma de decisiones comerciales sin necesidad de abrir el código fuente.

---

## Requisitos y ejecución

No requiere instalar dependencias externas (`npm install` no es necesario); funciona de forma nativa con **Node.js**.

1. Abre una terminal en la carpeta raíz del proyecto (`cafe-origen-analitica`).
2. Ejecuta el reporte ejecutivo completo con el comando:

```bash
node src/reporte.js
